# **COMPLETE SOCIAL MEDIA AUTOMATION & AI CONTENT PLATFORM**
## **Master Development Prompt - Task-Based Implementation Guide**

---

## **PROJECT OVERVIEW**

Build a production-ready, enterprise-grade social media automation platform with multi-AI integration, Instagram automation, content management, SEO optimization, and multi-platform publishing capabilities.

**Tech Stack Requirements:**
- **Frontend:** React 18+ with TypeScript, TailwindCSS, Framer Motion
- **Backend:** Node.js/Express or Python/FastAPI
- **Database:** PostgreSQL + Redis for caching
- **AI Integration:** OpenAI (ChatGPT), Anthropic (Claude), Google (Gemini), NVIDIA NIM APIs, xAI (Grok)
- **Social APIs:** Meta Graph API (Instagram/Facebook), Pinterest API, LinkedIn API, Snapchat Marketing API
- **Task Queue:** Bull/Redis or Celery
- **Real-time:** Socket.io or WebSockets
